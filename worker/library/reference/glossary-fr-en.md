Bell Business Markets projects run in two languages. A steering committee in Montréal may hold its meeting in French while the vendor's status report arrives in English, and a status report written for a Québec executive reads better in French. This glossary gives the French term a project manager is most likely to hear or need for each common English term, with a one-line meaning in Compass's own words. It is a working vocabulary, not a translation standard: where your organisation, a contract or the customer uses another term, follow them.

## How to read the table

- Terms are in alphabetical order by English. Search the library for either language to land here.
- Where Québec and France commonly use different words, both are given and marked: **(QC)** for usage common in Québec and in Canadian French generally, **(FR)** for usage common in France. A term with no mark is used on both sides.
- Where two French terms are listed without marks, both are in common use.
- Acronyms in brackets are the English ones (CPI, SPI, WBS). French acronyms are given only where they are in everyday use, such as ENS for an SLA or COPIL in France.
- PRINCE2 and PMBOK have official French editions whose wording sometimes differs from everyday usage; in a certification context, use the edition's own terms.

| Accept (risk response) | accepter | Choosing to live with a risk, with or without money or time set aside for it. |

| Acceptance criteria | critères d'acceptation | The checks a deliverable has to pass before anyone signs for it. |
| Action item | action à réaliser | A piece of follow-up work from a meeting, with one owner and a date. |
| Action log | registre des actions | The running list of open and closed action items for a project. |
| Activity | activité | A scheduled piece of work with a duration, smaller than a work package. |
| Actual cost (AC) | coût réel | What has really been spent on the work done so far. |
| Agenda | ordre du jour | The list of topics, in order, that a meeting will cover. |
| Agile | agile | Delivering in short cycles and adjusting the plan from what each cycle teaches. |
| Agreement | entente (QC); accord (FR) | A settled arrangement between parties, written or not. |
| Analogous estimating | estimation par analogie | Estimating from the actual figures of a similar past project. |
| Assumption | hypothèse | A belief the plan depends on that has not been checked yet. |
| Assumption log | registre des hypothèses | Where assumptions are listed with who confirms each one and by when. |
| Audit | audit; vérification (QC, public sector) | An independent check that work or records meet a standard. |
| Avoid (risk response) | éviter | Changing the plan so a threat can no longer occur. |
| Backlog | carnet de produit (QC); backlog (FR) | The ordered list of work still to be done on a product. |
| Baseline | référence de base | The agreed snapshot of scope, schedule or cost that you measure progress against. |
| Benefit | bénéfice; avantage | A measurable gain the organisation expects from the project's outcome. |
| Benefits realization | réalisation des bénéfices | Making sure promised benefits actually arrive, often after the project ends. |
| Bottom-up estimating | estimation ascendante | Estimating each work package and adding them up. |
| Budget | budget | The money approved for the project, usually split by phase or category. |
| Budget at completion (BAC) | budget à l'achèvement | The total planned budget for all the work in scope. |
| Buffer | tampon; marge de sécurité | Time or money held back to absorb variation without moving a commitment. |
| Business analyst | analyste d'affaires (QC); analyste métier (FR) | The person who turns business needs into clear requirements. |
| Business case | dossier d'affaires (QC); étude de rentabilité (FR) | The argument that a project is worth its cost and risk. |
| Business requirement | exigence d'affaires (QC); exigence métier (FR) | A need stated from the business's point of view rather than the system's. |
| Change control | maîtrise des changements; contrôle des changements | The process that assesses and decides proposed changes to an agreed baseline. |
| Change control board | comité des changements | The group with authority to approve or reject change requests. |
| Change freeze | gel des changements | A period when no changes are allowed, often around a cutover or year end. |
| Change management (organisational) | gestion du changement | Helping people adopt a new way of working; not the same as change control. |
| Change request | demande de changement (QC); demande de modification (FR) | A written ask to change what was agreed on scope, time, cost or quality. |
| Closing | clôture | The final phase: acceptance, handover, contract and financial closure. |
| Closure report | rapport de clôture | The document that records how the project ended against its goals. |
| Communication plan | plan de communication | Who receives which information, how often, through which channel and from whom. |
| Configuration management | gestion de la configuration | Keeping track of versions of deliverables and documents and what changed. |
| Constraint | contrainte | A fixed limit the project must work within, such as a date or budget. |
| Contingency reserve | réserve pour aléas; réserve pour imprévus | Money or time in the baseline kept for risks you already know about. |
| Continuous improvement | amélioration continue | Small, regular changes to how work is done, based on what is learned. |
| Contract | contrat | A legally binding agreement on what will be delivered and paid. |
| Cost baseline | référence de base des coûts | The approved, time-phased budget used to measure cost performance. |
| Cost performance index (CPI) | indice de performance des coûts | Earned value divided by actual cost; below 1 means overspending. |
| Cost variance (CV) | écart de coût | Earned value minus actual cost; negative means over budget. |
| Cost-plus contract | contrat à prix coûtant majoré | The buyer pays the seller's costs plus an agreed fee or margin. |
| Critical path | chemin critique | The chain of dependent work that sets the earliest finish date. |
| Customer | client | The organisation that pays for and receives the result. |
| Cutover | basculement; bascule | The moment service moves from the old setup to the new one. |
| Daily scrum | mêlée quotidienne (QC); daily, point quotidien (FR) | A short daily team check on progress toward the sprint goal. |
| Dashboard | tableau de bord | A one-screen view of a few key measures. |
| Deadline | échéance; date limite | The date by which something must be finished. |
| Decision log | registre des décisions | The dated record of decisions, who made them and any conditions. |
| Decomposition | décomposition | Breaking work into smaller parts until each can be owned and estimated. |
| Definition of done | définition de « terminé » | The shared checklist an item must meet before it counts as finished. |
| Deliverable | livrable | Something tangible the project has to hand over, such as a design, a working site or a report. |
| Dependency | dépendance | A link where one piece of work needs another to start or finish first. |
| Deployment | déploiement | Rolling a solution out to its users or sites. |
| Downtime | interruption de service; temps d'arrêt | The period during which a service is unavailable. |
| Duration | durée | Working time an activity takes from start to finish. |
| Earned value (EV) | valeur acquise | The budgeted value of the work actually completed. |
| Earned value management | gestion de la valeur acquise | Measuring progress by comparing planned value, earned value and actual cost. |
| Email | courriel (QC); e-mail, mail (FR) | An electronic message; courriel is also the official term in France. |
| Enhance (opportunity response) | améliorer | Raising the probability or benefit of an opportunity. |
| Escalation | escalade | Raising a problem to a higher authority because it is beyond your own. |
| Estimate | estimation | A reasoned forecast of effort, duration or cost, ideally as a range. |
| Estimate at completion (EAC) | estimation à l'achèvement | The current forecast of the project's total cost. |
| Estimate to complete (ETC) | estimation pour achèvement | The forecast cost of the work still left to do. |
| Exception plan | plan d'exception | A revised plan for the rest of a stage, approved after an exception report. |
| Exception report | rapport d'exception | A report raised when a tolerance is forecast to break, with options and a recommendation. |
| Executive summary | sommaire (QC); synthèse (FR) | A few lines at the top giving the essentials and the ask; sommaire exécutif is a common calque. |
| Expert judgement | jugement d'expert | Using the experience of people who have done similar work. |
| Exploit (opportunity response) | exploiter | Acting so that an opportunity is sure to happen. |
| Feasibility study | étude de faisabilité | An early check that an idea can work technically and financially. |
| Fixed-price contract | contrat à prix fixe; contrat au forfait (FR) | The seller delivers the agreed scope for an agreed price and carries the cost risk. |

| Forecast | prévision | An estimate of future dates or costs based on performance so far. |
| Free float | marge libre | Slip an activity can absorb without delaying its next activity. |
| Gantt chart | diagramme de Gantt | A bar chart of activities against time. |
| Go / no-go decision | décision go / no go; décision de poursuivre ou non | The choice, at a gate or before a cutover, to proceed or stop. |
| Go-live | mise en service; mise en production (IT) | The moment a new service starts being used for real. |
| Governance | gouvernance | Who decides what on a project, and how decisions are made and escalated. |
| Handover | transfert (à l'exploitation); passation | Passing a finished deliverable and its support to the people who will run it. |
| Impact | impact; incidence | How much a risk or issue would affect objectives. |
| Implementation | mise en œuvre; implantation (QC) | Putting a plan or solution into effect. |
| Incident | incident | An unplanned interruption or degradation of a service. |
| Increment | incrément | A usable piece of product finished during a sprint. |
| Invoice | facture | A seller's request for payment for delivered work. |
| Issue | problème; enjeu (QC) | Something that has happened and is affecting the project now. |
| Issue log | registre des problèmes; registre des enjeux (QC) | The list of open and closed issues with owners and actions. |
| Iteration | itération | A fixed, short cycle of work that ends with something to review. |
| Kanban board | tableau kanban | A board with columns for each step, showing work as it flows. |
| Key performance indicator (KPI) | indicateur clé de performance | A measure chosen because decisions depend on it. |
| Kick-off meeting | réunion de lancement | The first meeting that starts the project or a phase with everyone involved. |
| Lead time | délai d'approvisionnement | The time between ordering something and receiving it. |
| Lessons learned | leçons apprises (QC); retour d'expérience, REX (FR) | What the project learned that should change how future work is done. |

| Make-or-buy decision | décision de faire ou d'acheter | Choosing whether to build something in-house or buy it. |

| Meeting | réunion; rencontre (QC) | A scheduled discussion; rencontre is very common in Québec offices. |
| Meeting minutes | procès-verbal; compte rendu | The written record of a meeting; procès-verbal is the more formal. |

## In practice

- Before your next French-language steering committee, check the terms on your slides against this table: échéancier, portée, livrable, jalon.
- Write the meeting's decisions in the language the meeting was held in, and keep the same term for the same thing throughout a document.
- In emails to Québec colleagues, prefer the (QC) terms: courriel, rencontre, soumission, gabarit.
- When a vendor's French term differs from yours, agree one term per project and put it in the communication plan.
- Ask Athena to write a French version of a status summary, then check its terms here before sending.
