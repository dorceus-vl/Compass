The library is Compass's own shelf of project-management know-how: short pages on frameworks, delivery, planning, people, risk, contracts, reporting and closing, plus templates and a glossary. Every page is written in Compass's own words, so it stays short, plain and ready to act on.

## Finding things

Open Library and type in the search box. Results appear as you type, ranked by how well the title and text match, with a one-line extract under each. Accents and capital letters do not matter, so "echeancier" finds "Échéancier". The last word you type also matches as a prefix, so "earn" already finds "earned value". The whole library is stored on your device, so search keeps working offline once you have opened Library once.

## Ask about this page

Each page has an "Ask about this page" button. It opens the copilot with that page as the starting point, so you can ask how to apply it to a project. The page text goes to the model as reference material, never as instructions.

## What else appears here

Lessons you record on personal projects appear under Lessons, so the next project can learn from them. Lessons from work projects never appear here. Imported documents appear under Imports, and imports are for personal use only. Pages link to each other with double square brackets, and a link opens the page in place.
